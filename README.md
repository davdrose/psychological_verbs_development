# How Children Map Psychological Verbs to Different Causes

This repository contains the experiments, data, analyses, and figures for a
developmental project on how **children (ages 3–9) and adults** map different
verbs onto different causes in a causal chain. When a chain of events leads to an
outcome, a **causal / "caused"** question ("who *caused* it?") tends to pick out a
**distal** cause, whereas a **lexical** question using the specific verb ("who
*broke* it?", "who *scared* her?") can pick out a more **proximal / direct** cause.
We ask how this mapping differs for **non-psychological vs. psychological** verbs
and scenarios, and how it changes across development.

📦 **OSF project** (materials, data, and pre-registrations): https://osf.io/4u7as/

## Experiments

There are three experiments, each with an **adults** version (jsPsych, hosted on
[Proliferate](https://proliferate.alps.science/)) and a **children** version
(run on [Lookit / Children Helping Science](https://childrenhelpingscience.com/)).
Each experiment is archived in its own folder under
[`code/experiments/`](code/experiments/) so we always have a record of exactly
what it looked like when it was run — see the
[experiments README](code/experiments/README.md) for full designs.

| # | Experiment | Between-subjects condition | Scenarios |
|---|---|---|---|
| 1 | **Absence** scenarios | non-psychological / psychological (physical / mental) | hurt, shock |
| 2 | **Verbs** (causal vs. psychological), between-subjects | non-psychological / psychological (control / experimental) | drum, balloon |
| 3 | **Scared vs. surprised** | — (single condition) | scared, surprised |

## Reproducing the analysis

Requires **Python 3** (`pandas`) and **R** (`readr`, `dplyr`, `tidyr`, `ggplot2`).

```bash
# 1. Clean the adult (Proliferate) data  ->  data/experimentN/adults/expN_adults.csv
python code/python/clean_exp1.py
python code/python/clean_exp2.py
python code/python/clean_exp3.py

# 2. Parse the children (Lookit) data    ->  data/experimentN/children/expN_children.csv
#    (needs the raw *identifiable*.json files locally; see "Data & privacy")
python code/python/parse_children.py

# 3. Generate the figures                ->  figures/expN/expN_development.{pdf,png}
cd code/R
Rscript exp1.R
Rscript exp2.R
Rscript exp3.R
```

## Data & privacy

All committed data are **anonymized**. The adult data live in
`data/experimentN/adults/` (with the raw Proliferate export under `raw/`). The
children data are parsed from raw Lookit exports into
`data/experimentN/children/expN_children.csv` containing only de-identified fields
(hashed child id, rounded age, gender, and the experimental factors/responses).

The **raw Lookit exports** (`*_all-responses-identifiable.json`) are identifiable
and are **git-ignored** — they are never committed. Keep them locally to re-run
`parse_children.py`. See [data/README.md](data/README.md) for details.

Children stimuli (videos / images) are hosted separately in
[`CSLouise/lookit_material`](https://github.com/CSLouise/lookit_material) and are
referenced by URL from the children experiment code.
