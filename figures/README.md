# Figures

Figures generated by the scripts in [`../code/R/`](../code/R), one subfolder per
experiment. Regenerate any figure by running `Rscript expN.R` from `code/R/`.

| file | experiment | y-axis | panels |
|---|---|---|---|
| `exp1/exp1_development.{pdf,png}` | 1 — absence scenarios | absence / direct | non-psychological · psychological |
| `exp2/exp2_development.{pdf,png}` | 2 — causal vs. psychological verbs | distal / proximal | non-psychological · psychological |
| `exp3/exp3_development.{pdf,png}` | 3 — scared vs. surprised | distal / proximal | single panel |

Each **developmental figure** shows the probability of choosing the distal (or
absent) cause for **caused** (red circles) vs. **lexical** (blue triangles)
questions across development — children by age (3–9, with a logistic-GLM trend and
per-age means) alongside the adult sample — with bootstrapped 95% CIs and sample
sizes annotated per age.
