# docs

This folder is the **GitHub Pages** publishing directory. When a rendered analysis
report is added (e.g. by knitting the R analysis in [`../code/R/`](../code/R) to
HTML), it will live here as `index.html` and be served at
`https://<owner>.github.io/psychological_verbs_development/`.

It is currently a placeholder. The figures are generated directly by the R scripts
in [`../code/R/`](../code/R) and saved to [`../figures/`](../figures); see the
top-level [README](../README.md) for how to reproduce them.
